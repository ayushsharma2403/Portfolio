## 🚀 Free Vercel Deployment (Under 2 Minutes)

### Option 1: Via GitHub & Vercel Dashboard (Recommended)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: spatial OS portfolio"
   git remote add origin https://github.com/ayushsharma2403/portfolio-os.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository, keep defaults (Static HTML), and click **Deploy**.
4. Done! Your portfolio is live with free global CDN and SSL.

### Option 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
Select default options and deploy directly from your local directory in seconds.
